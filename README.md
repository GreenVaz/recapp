# Особистий фінансовий облік

Веб-застосунок для обліку витрат, бюджетування та аналітики особистих фінансів.
Мультивалютність, інтеграція з Monobank API і швидке додавання витрат з iPhone
через Apple Shortcuts.

## Швидкий старт

```bash
npm install
cp .env.example .env
# згенеруйте ключ шифрування:
#   openssl rand -hex 32   → вставте в APP_SECRET

npm run setup        # створює БД і наповнює категоріями та MCC-правилами
npm run db:demo      # опційно: демо-дані за 6 місяців, щоб побачити дашборд
npm run dev          # http://localhost:3000
```

Очистити демо-дані: `npm run db:demo -- --reset`.

## Що вміє

**Рахунки.** Готівка, картки, банки, заощадження в UAH / USD / EUR.
Ручне коригування балансу, архівація замість видалення історії.

**Транзакції.** Витрати, доходи, перекази між рахунками — зокрема
крос-валютні з окремою сумою зарахування. Фільтри за типом, рахунком і
пошук за приміткою; групування по днях.

**Категорії.** Дворівнева структура (категорія → підкатегорія), понад 60
іконок і власні кольори. У сіді вже є 56 категорій і 83 MCC-правила.

**Бюджети.** Місячні ліміти на категорію або підкатегорію, прогрес-бари
зелений / жовтий / червоний (< 80% / < 100% / ≥ 100%), зведений
прогрес по місяцю.

**Регулярні платежі.** Підписки, оренда, комуналка з періодичністю
тиждень / місяць / квартал / рік, нагадуванням за N днів на дашборді
і проведенням одним кліком.

**Monobank.** Токен зберігається зашифрованим (AES-256-GCM), запити
йдуть лише з сервера. Підтягуються рахунки, картки та банки, баланси й
виписка за період; транзакції дедуплікуються за id операції, категорія
присвоюється автоматично за MCC-кодом або ключовим словом в описі.

**Дашборд.** Глобальний фільтр (період, рахунок, категорія) і шість
модулів аналітики: структура витрат (donut із розкриттям підкатегорій),
доходи vs витрати (combo), тренд чистого капіталу, бюджет vs факт,
топ-5 категорій та найбільших операцій, накопичення наростаючим підсумком.

## Швидке додавання з iPhone

У «Налаштуваннях» згенеруйте API-ключ, далі — POST або GET:

```bash
curl -X POST https://ваш-домен/api/quick-entry \
  -H "X-API-Key: pft_…" \
  -H "Content-Type: application/json" \
  -d '{"amount": 149.50, "note": "Кава", "category": "Кава"}'
```

```
GET /api/quick-entry?key=pft_…&amount=149.5&note=Кава
```

Поля: `amount` (обовʼязкове, у звичайних одиницях), `type`
(`EXPENSE` / `INCOME` / `TRANSFER`, за замовчуванням витрата), `account`,
`toAccount`, `category`, `note`, `date`, `tags`. Рахунок і категорію можна
вказувати назвою — пошук нечіткий. Приймається і `form-urlencoded`, який
Shortcuts шле за замовчуванням.

Відповідь містить `message` — готовий рядок для нотифікації або Siri.
Покрокова інструкція зі створення команди є на сторінці налаштувань.

> Кирилицю в query-параметрах потрібно URL-кодувати — Shortcuts і браузери
> роблять це самі, а `curl` з голим текстом отримає 400 від HTTP-парсера.

## Безпека

Це single-user застосунок для самостійного хостингу: моделі користувачів і
сесій немає. Токен Monobank і API-ключ шифруються `APP_SECRET`, API-ключ
звіряється через `timingSafeEqual`. Перед публічним розгортанням додайте
автентифікацію і винесіть дані під `userId` — деталі в
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
